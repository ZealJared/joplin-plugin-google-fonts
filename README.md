# Joplin Plugin: Google Fonts

This plugin allows you to style selected text in the Joplin note-taking application with fonts from Google Fonts. It enhances the customization of your notes, making them more visually appealing by giving you access to a wide variety of fonts.

## Features
- Apply Google Fonts to selected text in Joplin's editor.
- Customize the appearance of notes by choosing from a large selection of fonts.
- Seamlessly integrates with Joplin, providing an enhanced note-taking experience.

## Installation

1. **Via Joplin's Plugin Manager:**
   - Open Joplin.
   - Go to `Tools > Options > Plugins`.
   - Search for `Google Fonts`.
   - Click `Install`.

2. **Manual Installation:**
   - Download the plugin from [GitHub](https://github.com/ZealJared/joplin-plugin-google-fonts).
   - Copy the `.jpl` file to Joplin's plugin directory:
     - For Windows: `%USERPROFILE%\\.config\joplin-desktop\plugins`
     - For macOS/Linux: `~/.config/joplin-desktop/plugins/`
   - Restart Joplin.

## Usage

Once installed, you can apply Google Fonts to your notes:
1. Highlight the text in the editor.
2. Use the plugin's font selection feature to choose a font from Google Fonts.
3. The selected font will be applied to the highlighted text.

## Requirements

- Joplin 2.0 or higher
- Internet connection to load fonts from Google Fonts
